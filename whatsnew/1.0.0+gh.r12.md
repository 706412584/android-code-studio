## Overview

本版集中修复三类「用户报上来但根因藏在链路深处」的问题：生图网关兼容、Dart SDK
安装、以及设置里缺失的入口。全部在真机（黑鲨 SKW-A0 / Android 10）上验证过。

---

## 生图：兼容只回外链的网关

之前用 loomy2api 这类网关生图会失败，报「服务商未返回图片数据」。三处独立原因：

- **不认普通外链结果**。网关忽略 `response_format=b64_json`，只回 https 图片链接，
  而客户端只认 base64 与 data URL。现已支持下载外链后落盘。
- **模型列表漏掉真模型**。筛选只按名字是否含 "image"，`doubao-seedream-5-lite`
  这类不含关键词的生图模型根本选不到。现优先按网关声明的模态筛选。
- **空密钥被误标「缺密钥」**。本地/局域网网关通常不鉴权，空密钥是正常配置，
  之前却显示「缺密钥」，让人以为配置没生效。现在这类端点显示「可用」。

顺带修掉一个诊断问题：全部失败时逐条原因被丢弃，只看到笼统的「无法解析」。
现在会带上「下载失败」「base64 解码失败」这类具体原因。

## 语言服务器

- **修复 Dart SDK 应用内安装必然失败**。两个独立缺陷：解包时多套了一层目录
  （`dart-sdk/dart-sdk/...`），以及发布包在 Windows 上重打包时丢了可执行位
  （`bin/dart` 没有 +x，解出来跑不了）。现在下载→解压→校验全链路可用。
- **TypeScript 语言服务器支持一键安装**。之前只提示「请在项目根执行 npm install」，
  现在设置页直接有安装按钮，用内置 Termux 的 node/npm 装到当前项目。

## 设置

- **新增「检查更新」入口**（设置 → 关于）。此前检查更新只在启动时静默执行，
  想主动确认有没有新版无从下手。手动检查有反馈：有更新弹更新窗，没有则提示
  「暂无可用更新」。
- **修复服务商改名产生重复记录**。改名后再看列表会多出一个同配置的服务商。
  根因是改名把记录主键也一起改了，现在改名只更新显示名。
