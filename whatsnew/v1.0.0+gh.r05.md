## Overview

本版本把「结绳语言基本库（ticode）」从"写完了但用户用不到"变成**真正能用**：
接入 Quick Develop 模板、在真机上端到端跑通、并用反射覆盖 + 静态扫描挖出并修复了
一批"编译通过、一跑就崩"的运行时缺陷。同时继续完善 AI 助手的多入口与真机工具链。

共 101 个提交。

## 主要改动

### 结绳库（ticode）接入模板并可用

1. **独立 `:ticode` 模块进生成工程**。新建的 Quick Develop 工程现在包含 333 个中文
   API 类（`ticode.zh.*`），`app` 自动 `implementation(project(":ticode"))`，用户可直接调用
   `加解密操作.MD5加密(...)`、`GZIP操作.压缩字节集(...)` 等。

2. **真机端到端验证**。在黑鲨 SKW-A0（Android 10）上：建工程 → 构建 APK → 安装 →
   启动 → 输入内容点按钮 → 界面显示 MD5 与 GZIP 往返结果，全链路跑通。

3. **反射覆盖度测量**：真机遍历 334 类全部 public 方法，执行覆盖 **89.9%（2881/3204）**。
   剩余 316 个方法所在类（Activity/Context/Drawable/PackageManager）必须真实 framework
   实例才能构造，属反射可达性的天花板，非库缺陷。

4. **静态扫描修掉三类"编译过、一跑崩"的缺陷**（覆盖度数字测不出的）：
   - **28 处强转 ClassCastException**：把框架返回值（`getResources`/`getPackageManager`/
     `loadIcon`/`getJSONObject` 等）强转成 ticode 壳子类，必崩。
   - **14 处 API 级别不匹配**：`compileSdk 36` 编译过，但 Android 10 上
     `NoSuchMethodError`（`WifiInfo.getWifiStandard` 等 API 30+ 符号）。
   - **误标 abstract 的 48 个类具体化**：这些类自身无抽象方法，只是翻译器沿用了
     结绳的 abstract 标注，导致用户无法 `new`。

5. **新增静态扫描与验证脚本**（`docs/ticode-port/coverage/`）：壳类强转扫描、方法清单
   生成、反射覆盖驱动、低版本 `android.jar` 编译检查法，可回归。

### Quick Develop 模板

1. **修复 P0：基础控件缺失通用样式方法**。文档承诺"所有组件都提供背景/圆角/内边距/
   外边距/权重"，但 `文本`/`按钮`/`输入框` 继承 `TextView`/`MaterialButton`/
   `TextInputEditText`（不是 `视图`），拿不到这些方法——用户照文档抄
   `new 文本(this).背景(c)` 直接编译失败。已补齐；`约束布局` 漏写的协变返回
   override 也补上（否则链式在 `.背景(c)` 后断掉）。

2. **修复生成的工程 README 渲染成代码块**：README 内嵌多行的选型指引后，
   `trimIndent()` 的公共缩进被拉平为 0，整份文档每行留 6 个前导空格，Markdown 会把它
   当代码块渲染。改用占位符 + 去缩进后替换。

3. **测试补强（22 → 31）**：
   - **生成的 88 个 UI/工具源码真正用 javac 编译**（此前只落盘、注释写"供外部验证"，
     实际从没编译过——改错一个继承类名，测试全绿，用户建工程才炸）。
   - 文档生成纳入测试（此前 `writeDocs()` 从未被执行过）。
   - 数量改为从真实来源派生，不再硬编码（曾写死"44"而真实是 45）。

4. **新增仓库级使用入口** `docs/quickdevelop/README.md`。

### AI 助手

1. **助手三入口统一**：内联页 / 真全屏 / 应用外悬浮三种宿主，多会话并行、内置子 agent、
   1M 上下文。
2. **真机测试工具链**：新增 16 个 `phone_*` 工具与 `http_request`，打通「构建 → 安装 →
   启动 → 交互 → 断言」闭环；接入 Shizuku 授权流程。
3. **CodeGraph 手动初始化项目索引**，下载失败给诊断代理。
4. 修复若干：应用外悬浮窗可真正全屏且与内悬浮互斥、提示词模板编辑框保存按钮被挤出、
   `phone_clear_data` 拒绝清除本应用自身、OpenAI 路径工具结果图片挂错消息等。
