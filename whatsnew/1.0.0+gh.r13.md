## Overview

本版围绕 AI 助手的**可用性**与**正确性**：修掉三处真机上能复现的界面缺陷、让跨项目会话不再
静默构建错项目、把会话导出从剪贴板改成文件，并补上 1000+ 条自动化测试（覆盖率 79% → 95%）。
全部改动都在黑鲨 SKW-A0 / Android 10 上验证。

---

## AI 助手界面

- **思考块展开后不再需要手动滑动**。此前展开一段长思考，内容超出屏幕后停在顶部，
  必须自己往上划才能看到最新推理；现在展开态会跟随输出自动滚到底部。
- **修复点击助手顶部 Git 图标闪退**。未打开任何项目时点它，进程直接崩掉——根因是
  某个全局单例在类加载时就读取项目目录并断言非空。现在改为惰性读取，无项目时给出提示。
- **修复生成图片重复显示两个「点击查看大图」**。折叠态与展开态各渲染了一份预览，
  折叠时看得见、展开后又出现一次。现在两者互补，任一时刻只有一个。
- **修复断流重试后残留推理块**。网络中断触发重试时，上一轮的思考卡片没有被清理，
  表现为一段空的「思考完成」卡片挂在对话里。根因是清理逻辑不穿透工具分组。
- **会话导出改为写文件**。此前「导出」只是把整段对话复制到剪贴板，长对话既不好用、
  也无法直接查看。现在写入 `Android/data/com.tom.rv2ide/files/exports/` 下的 Markdown
  文件，并直接弹出「用其他应用打开」；路径同时进剪贴板。

## AI 助手：跨项目会话

- **构建类工具不再静默用错项目**。会话可以绑定任意项目目录，但 `gradle_build` /
  `build_variant` / `test_coverage` 此前只服务编辑器当前打开的项目——会话绑 B、
  编辑器开着 A 时，它会安静地构建 A 并把结果当成 B 的。现在检测到不一致会明确拒绝，
  并提示「先打开目标项目，或改用 shell_execute 跑 ./gradlew」。
- **新建会话的项目选择器会标注**：选中非当前打开项目时，显示「（构建需先打开）」，
  避免选完才发现构建用不了。

## AI 助手：工具与稳定性

- **修复 stdio MCP 连接断开后请求静默返回空结果**。子进程退出时等待者被唤醒，
  但从不检查失败原因，工具层把「进程死了」当成「server 回了个空结果」。
  现在如实报错并带上 stderr 尾巴。
- **修复 SSE 传输的错误原因被覆盖**。endpoint 事件给出非法地址后，读循环继续在已关闭
  的流上读，把真实原因盖成 `Stream closed`。
- **修复图像处理的内存不足会穿透工具层**。解码是最大的内存分配点，但它原本不在
  `catch (Throwable)` 覆盖范围内，OOM 会直接打掉整个 agent 循环。
- **修复图像/视频工具的输出目录判定**。目录路径被文件占住时，用户只会看到
  `Not a directory`，而不知道是保存目录配置错了。
- **修复 RSS 搜索结果标题带出 `]]>` 残留**（CDATA 未剥离）。
- **修复诊断工具在目录被截断时不提示**。只扫描了部分文件却报「未发现问题」，
  会让模型以为整个目录都干净。
- **修复 Agnes 视频轮询的零间隔热循环**。瞬时失败后退避计算会得到 0 毫秒，
  变成疯狂重试把上游打爆。

## 构建与工程

- **接入 kover 覆盖率**：`ai-tool-api` / `ai-protocol` / `ai-tool` / `ai-agent` 四个
  纯 JVM 模块，新增 `test_coverage` 工具可直接向 AI 汇报未覆盖的类与方法。
- **接入构建健康四件套**：dependency-analysis（依赖健康）、doctor（环境体检）、
  test-retry（失败用例自动重试）、version-catalog-update（依赖目录升级）。
- **测试从 ~560 条扩到 1127 条**，`core/ai-tool` 行覆盖率 95.07%。
