## Overview

本版围绕**多标签页多项目**与**构建链路**：把项目会话从单例拆成可并行的 Session/Registry，
修复切标签卡死与切回后构建失效，并把构建连接按会话 cwd 路由。同时补上 Root（su）shell
后端、AI 助手工具调用上限默认不限，以及影子屏接入视觉回归。

安全侧修掉两条真实可利用的缺陷：`logcat_read` 的 level 参数可注入 shell 命令；
`shell_execute` 的「始终允许」规则不区分后端，Termux 下放行的命令可被改填 `root` 后静默提权。

全部改动在黑鲨 SKW-A0 / Android 10 上验证。

## 多标签页多项目

- **标签切换卡死修复**。LSP 重新路由原先串在切换关键路径上，第二个标签打开后界面停在
  第一个、点标签也切不动，状态显示「项目已初始化」但进度条一直转。现在 LSP 路由移出关键路径。
- **切回已同步标签后构建返回 `PROJECT_NOT_INITIALIZED`**。根因是切走时关闭了仍有存活
  tooling 进程的连接，切回时新建的连接对应一个从未同步过的 server。现在切走降级为后台、
  切回复用并 `promoteToEditor`，后台连接按 TTL/数量回收。
- **关闭非活跃标签不再崩溃**。QuickRun 全链路加异常兜底——原先 `saveAllResult` 抛异常
  会直接杀进程，表现为「标签只剩一个」。
- **打开文件缓存恢复加代际令牌**。快速切标签不再把 A 项目的打开文件写进 B 项目。
- **项目同步回调绑定发起时的会话**。回调原先可能写到另一个项目的会话上。
- **Chip 判据改用编辑器实际显示的项目**，不再依赖可能脱节的注册表指针。

## 构建链路

- **ToolingConnection 抽象**（P1）：`GradleBuildService` 改为连接壳，行为不变。
- **按会话 cwd 路由构建连接**（P2）：会话绑定 B 项目、编辑器开着 A 时，构建不再静默作用在 A 上。
- **后台项目构建**（P3）：未打开的项目也可构建，默认关闭（每连接约 2GB 堆上限，低端机可能 OOM）。
- **APK 定位去全局化**（P4）：排除 `androidTest` 产物；`output-metadata.json` 的
  `applicationId` 改读顶层（原永远读不到）。
- **全局构建并发闸门**（P5）：避免多个 tooling JVM 同时拉起。
- **AAPT2 override 与跨项目 APK 定位**：修复 P1 重构丢失的路径。

## AI 助手

- **工具调用次数上限默认不限**。此前硬编码 100 次，真实排查/重构任务到上限就硬停，
  任务做了一半被截断。现在默认不限，额度约束由用户手动停止与可选总时长预算承担。
- **新增 Root（su）shell 后端**。可显式选择 `backend=root`；权限规则键含后端 id，
  必须经用户确认，不会被 Termux 下的放行规则复用。
- **影子屏接入视觉回归**。`vscreen shot` 新增 `inline=false`，只返回原分辨率 PNG 路径；
  `phone_baseline` / `phone_screenshot_compare` / `phone_action_capture` / `phone_ocr`
  新增 `display=vscreen`，基线保存、回归对比、动作连拍、OCR 都能跑在虚拟屏上，不占用用户主屏。
- **OCR 坐标提示按来源区分**。影子屏场景提示传给 `vscreen` 的 tap，不再一律写 `phone_click`
  （那会让模型点到用户主屏）。
- **修复并行子 agent 的进度串卡**。多张卡片同时运行时，进度行按调用 id 归卡，
  不再写进另一张仍在跑的卡片。
- **后台构建开关**：默认关闭，需在设置里显式开启。
- 精简后端与助手文案。

## 安全

- **`logcat_read` 的 level 参数加白名单**（V/D/I/W/E/F/S）。原先未校验就拼进 shell 命令，
  而该工具属 READ 类别、默认不确认——后端为 root 时是一条 root 执行路径。
- **`shell_execute` 的权限规则键纳入 backend**。用户在 Termux 下「始终允许」过的命令，
  模型改填 `backend="root"` 不再命中同一规则。
- **Root 探测加固**：总预算 15s、失败 TTL 30s、并发读取、`invalidateCache` 加锁、
  探测耗时计入超时；新增 `isPresent()` 只查文件存在，生成提示词时不再 fork `su`。
- **`git_write` 与只读 `git` 拆分**，权限按工具分级。

## 其他修复

- **核心库脱糖失效导致点 Git 闪退**。jar 依赖曾被「名字含 desugar 就禁用」的规则连带
  禁掉，`openjdk.tools.javac.**` 整体缺失。
- **更新下载进度条无限重置**。进度条不再从 0 反复跳。
- **启动时更新弹窗被遮挡**。先让更新检查跑完再打开上次项目，弹窗不再挂在不可见 Activity 上。
- **本地构建版本号落后线上**。`versionCode`/`versionName` 现回落读仓库根 `updater.json`，
  本地 `assembleDebug` 不再固定拿到旧版本号。
- 会话导出改为写文件（`files/exports/` 下的 Markdown）。
- 断流重试后不再残留空推理块；思考块展开态跟随输出自动滚到底部。
