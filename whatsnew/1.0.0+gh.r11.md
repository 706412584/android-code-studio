## Overview

本版本是 r10 的**审查跟进版**：r10 的性能与稳定性修复（markdown 无限重组、
重试卡死、400 超限恢复、局域网模型）经独立代码审查后，修掉了三处细节问题。
如果你还没升级到 r10，直接装这个版本即可获得全部修复。

---

## r10 主要内容（本版已包含）

- **修复 AI 助手面板持续重组**（CPU 100%、发烫、掉帧——markdown 渲染器的
  remember 失效导致无限自激循环）
- **修复网络错误重试时应用卡死**（错误日志写入 MB 级单行文本，编辑器测量
  每次冻结主线程 1.4 秒）
- **修复 400 上下文超限无恢复**（图片未计入 token 估算 + 超限后自动收缩重试）
- **修复局域网 LLM 无法拉取模型**（明文 HTTP 白名单不支持网段）
- 子代理工具调用上限取消（原 40 轮强制中断）

## 本版跟进修复（审查发现）

1. **超限误判收紧**。上下文超限的错误特征匹配过宽——`invalid context length`
   这类参数错误会被误判成超限，白白裁掉一半历史再重试。已收紧关键词。
2. **异常消息截断补全**。r10 只截断了日志，异常消息仍携带完整响应体——
   服务端回显整个请求时会经异常一路上浮到界面（与卡死修复同一根因的另一半）。
3. **超限收缩的兜底预算**。本地估算低估（超限的常见成因）时，收缩目标可能
   大于实际预算导致「判定未收缩、不重试」——恰是最需要重试的场景。已改为
   取「当前估算一半」与「窗口绝对预算一半」的较小者。
