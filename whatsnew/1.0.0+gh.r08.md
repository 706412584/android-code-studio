## Overview

本版本是 AI 助手的一次大规模能力扩充：新增**后台命令执行**、**终端会话读取**、
**多子 agent 流水线**，让助手从「一次一步」升级为「能并行、能等待、能看见你在终端里做什么」；
同时修掉一类**数据安全级缺陷**——AI 改文件后编辑器不同步、自动保存会静默覆盖 AI 的修改。
此外补上内置浏览器、图片/视频生成、技能市场、stdio MCP、诊断自省等一批工具，
并新增 Compose Multiplatform 项目模板。

## 主要改动

### AI 助手：后台命令执行（不再干等）

1. **`shell_execute` 支持 `run_in_background`**。跑一次 8 分钟的构建时，助手不再全程干等——
   启动即返回任务 id，完成时自动收到通知，中间可以继续读代码、做别的调查。
   日志流 / dev server 这类永不退出的命令也从「不可能」变为可用。

2. **配套 `task_output` / `task_stop`**。按 id 取回输出与状态（可阻塞等待或非阻塞查看）、
   必要时停止。输出写入文件而非内存，命令可以输出任意长而不撑爆上下文。
   语义照 cc-haha 的 BashTool / TaskOutput / TaskStop。

3. **完成通知两条路径**：会话仍在跑 → 通知注入循环，助手下一轮自动看到；
   会话已结束 → 发状态栏通知。两条都不做的话，后台命令完成就石沉大海。

### AI 助手：终端会话读取

4. **`terminal_read`**。`shell_execute` 每次起独立进程，看不见你在终端里手动跑的东西。
   现在助手能直接读内置终端（Termux）会话的屏幕内容——你跑了个报错的命令让它看，
   它不必再让你复制粘贴。只读，不向你的终端注入命令。

### AI 助手：多子 agent 流水线

5. **`agent_pipeline`**。一次编排多个子 agent：每个子任务可声明 `depends_on`（等待上游完成）
   与 `write_scope`（写入范围）。同层任务并行执行，上游的结论自动注入下游。
   适合「先调研 A、B，再基于两者实现 C」这类有依赖的多步工作。
   执行前挡掉重复 id、循环依赖、悬空依赖、**同层写范围冲突**（竞态）。

6. **子代理补上 `grep`**。此前 explore / 审查子代理只能 glob 出文件名、再逐个整文件读——
   「哪里用了这个 API」会白读几十个文件。现在与主 agent 一样能按内容搜索。

### AI 助手：编辑器同步（数据安全）

7. **AI 改文件后编辑器自动刷新**。此前 `file_write` / `file_edit` 直接写盘，打开着该文件的
   编辑器不知道——你看到的是旧内容，需要手动关掉重开。

8. **修掉「自动保存覆盖 AI 修改」**（数据丢失级）。更危险的是：你随后在编辑器里随手改一笔，
   2 秒自动保存会把编辑器里的旧内容整段写回磁盘，**静默覆盖 AI 的修改**。
   现在编辑器检测到磁盘被外部改写时会标记冲突、让自动保存让路，由你决定以哪边为准。

### AI 助手：新增工具

9. **内置浏览器**（`browser`）：用系统 WebView 渲染网页，可取 innerText、跑 JS、截图——
   面向 SPA 与需要视觉确认的场景（替代此前不可用的 Playwright 路线）。

10. **图片 / 视频生成**：`image_generation` / `video_generation`，能力页配置服务商
    （Agnes 等兼容端点）。生成结果落盘 + 内联预览，不再把 base64 塞进上下文。

11. **技能市场**：从 ClawHub / SkillHub 安装 skill（sha256 校验、一键安装/卸载），
    输入框支持 `@` 选择、`/技能名` 触发。

12. **stdio MCP 传输**：可在 Termux 里起本地 MCP server（newline-delimited JSON-RPC）。

13. **IDE 自省**：`diagnostics`（编译诊断，编辑后搭车附上）+ `ide_log_read`（读 IDE 自身日志）
    + `memory_analysis`（内存画像）+ `layout_preview`（布局预览）。

14. **手机开发工具补齐**：`archive`（压缩/解压）、`lsp_navigate`（跳定义/找引用）、
    `format_code`（格式化）、`project_info`（模块/变体/任务名）。

### 界面与体验

15. **Compose 渲染层**：消息卡片、思考块、工具卡、抽屉、输入栏全部迁移到 Compose
    （移植自 Aharou），4 套消息配色主题，历史回放性能优化（批量通知 + contentType）。

16. **运行完成通知**：面板不可见且你 6 秒无交互时，状态栏提醒（cc-haha 语义）。

17. **多项稳定性修复**：悬浮窗多层崩溃（LifecycleOwner / OnBackPressedDispatcherOwner）、
    服务商弹窗文字不可见、流式输出不跟随滚动、历史回放滚底、上下文按钮判据等。

### 模板

18. **新增 Compose Multiplatform 项目模板**：含三 OS 矩阵的云端出包 workflow、
    国内镜像仓库、向导卡片中文描述、预览图。

## 已知限制

- 后台命令的输出是**命令结束后一次性交付**，非流式：构建进行中 `task_output` 看不到中间输出。
- `gradle_build` 暂不支持后台执行（走构建服务单例，并发语义与 shell 不同，另议）。
- 终端读取**只读**：不支持向你的终端注入命令。
