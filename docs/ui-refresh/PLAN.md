# 主 App UI 升级

- 分支：`feat/main-app-ui-refresh`；基线：`5c881094`（本地 `dev`）。
- 目标：参考独立 ACS 助手的留白、语义色、弱描边和文字层级，统一首页、项目入口、ATC 向导、设置与编辑器外壳。
- 技术：保留 XML/ViewBinding，复用主 App 已有 Compose 主题；不增加模块，不依赖 `assistant:*`。
- 保留：五种主题、已保存的有效主题与明暗模式、七个首页入口、模板生成/构建/LSP/项目会话行为。未设置或无法识别主题时默认使用暖阳和煦。

## 阶段交付

1. 主题基础、首页与项目入口。
2. ATC 向导与旧导航兼容。
3. 设置、编辑器外壳与助手边界。
4. 浅深/主题/字体/横屏/IME 验收与最终差异。

每阶段检查既有实现与调用者，优先复用，不做无关重构。布局变体同步处理；新样式显式应用到目标页面，避免全局污染。未获授权不提交、推送、合并或发布。
